#+begin_center

* Namida player for Nix/Home Manager

[[/iWisp360/namida-nix/issues][Plz Contribute]]

This flake brings you a native derivation for *Namida*, as well as a *home
manager* module for configuration if you want to.

#+end_center

** Installation

#+begin_quote
These steps assume you already set up home manager with flakes and you are
ready to import modules to your =home.nix=, if you already didn't do so,
checkout [[https://nix-community.github.io/home-manager/index.xhtml#ch-nix-flakes][these docs]]
#+end_quote

Feel free to skip steps you have already done before

1. Enable unfree nixpkgs

   #+begin_src nix
     # configuration.nix
     nixpkgs.config.allowUnfree = true;
   #+end_src

2. Add to your flake inputs

   #+begin_src nix
     # flake.nix
     inputs = {
       namida.url = "git+https://codeberg.org/iWisp360/namida-nix";
     };
   #+end_src

3. Import the home manager module

   #+begin_src nix
     # home.nix
     imports = [
       inputs.namida.homeManagerModules.namida
     ];
   #+end_src

4. Enable namida

   #+begin_src nix
     # home.nix
     programs = {
       namida.enable = true;
     };
   #+end_src

#+begin_quote
A package is also offered, if you want just the package, you may want to add to
your home.packages or environment.systemPackages the package
=inputs.namida.packages.${system}.default=, or if you aren't using flakes at
all, you can add this to your packages
#+end_quote

#+begin_src nix
  (pkgs.callPackage (builtins.fetchGit {
    url = "https://codeberg.org/iWisp360/namida-nix";
    rev = "f64a633de773a826b11c8d1ffe72bfb17bb62619"; # latest revision where nix/default.nix got modified
  }) { })
#+end_src

** Configuration

For further configuration, see [[file:docs.md][docs.md]] to know the available options for this
module.

Here is an example on how you would configure namida through home manager:

#+begin_src nix
  programs.namida = {
    enable = true;
    settings = {
      enable = true;
      appearance.pitchBlack = true;
      customization.blur = true;
    };
  };
#+end_src
